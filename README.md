# Последний ящик / Cargo Loop — 0.2.9

[Играть в браузере](https://snwlmw.github.io/cargo-loop-play/)

500 уровней кампании и каталог 2500 проверенных уникальных раскладок для трёх режимов аркады. Погрузка в следующую машину разрешается после проверки выигрышного продолжения; при неопределённости цепочка останавливается на первом кузове. Есть отдельные сохранения, обучение, светлая и тёмная темы, музыка, первый ящик + четыре следующих и ввод промокода обычным браузерным полем.

Недельные и месячные топ-50 используют явно обозначенных вымышленных соперников с ежедневными изменениями. Очки и место самого игрока учитывают его реальные завершённые забеги; место закреплено под списком.

Здесь находится готовая браузерная сборка. Проект Godot хранится в закрытом репозитории. ZIP собирается из частей web-parts/ с проверкой SHA256 и публикуется GitHub Pages.
