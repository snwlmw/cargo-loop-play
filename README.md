# Последний ящик · Cargo Loop

**[Играть в браузере](https://snwlmw.github.io/cargo-loop-play/)**

Уютная головоломка с цветными ящиками, мягкой музыкой и светлой/тёмной темой. 40 уровней и 100 дополнительных задач. Можно играть с телефона без установки APK; прогресс сохраняется в этом браузере.

Здесь размещена только готовая браузерная сборка 0.1.3 и настройка её публикации на GitHub Pages. Исходный проект хранится в закрытом репозитории. Лицензии движка Godot и шрифтов Noto доступны внутри игры в настройках.
